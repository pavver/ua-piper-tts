# Output Language Instruction

## Мовна інструкція для Qwen Code

**Обов'язкова вимога:** Всі відповіді, пояснення, коментарі та комунікація з користувачем мають бути **виключно українською мовою**.

### Правила:
1. Відповідай тільки українською мовою
2. Не використовуй інші мови у відповідях користувачу
3. Технічні терміни (команди, назви файлів, код) залишай без змін
4. Коментарі в коді мають бути англійською (для сумісності з GitHub)
5. Документація (.md файли) може бути українською або англійською залежно від призначення файлу

### Винятки:
- Якщо користувач явно просить відповідь іншою мовою — використовуй запрошену мову
- Код, команди, шляхи, логи — залишай без перекладу
