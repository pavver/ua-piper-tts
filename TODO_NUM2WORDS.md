# TODO — num2words Українські проблеми

> Проблеми та workaround-и крейту `num2words v1.2.0` (`Lang::Ukrainian`)
> Цей файл — збірний документ для майбутнього виправлення в самій бібліотеці.

---

## 🔴 Проблема 1: "один цілих" замість "один цілий"

### Опис
При конвертації десяткових чисел `num2words` завжди використовує "цілих" як незмінну частину, але в українській мові після числівника **один** має бути **цілий** (чоловічий рід), а після **два** — **цілих** (але з фемінативом "дві" замість "два").

### Приклади
| Ввід | num2words | Очікується |
|------|-----------|------------|
| `1.5` | `один цілих п'ять десятих` | `один цілий п'ять десятих` |
| `2.5` | `два цілих п'ять десятих` | `дві цілих п'ять десятих` |
| `3.5` | `три цілих п'ять десятих` | ✅ `три цілих п'ять десятих` |

### Current workaround
```rust
.replace("один цілих", "один цілий")
.replace("два цілих", "дві цілих")
```

### Що виправити в num2words
У функції форматування десяткових чисел для української мови потрібно узгоджувати "цілий/ціла/ціле/цілих" з родом числівника перед комою:
- `1` (один) → `цілий` (чол. рід)
- `2` (два) → `цілих` (але числівник → `дві`)
- `3+` → `цілих`

## 🟡 Проблема 2: Десятковий формат "кома ..." замість "цілих ... десятих"

### Опис
`num2words` використовує формат `"ціле число кома десяткове число словами"`. Це не відповідає стандартній українській вимові десяткових дробів.

### Приклади
| Ввід | num2words | Очікується |
|------|-----------|------------|
| `36.6` | `тридцять шість кома шість` | `тридцять шість цілих шість десятих` |
| `3.14` | `три кома чотирнадцять` | `три цілих чотирнадцять сотих` |
| `0.001` | `нуль кома нуль нуль один` | `нуль цілих одна тисячна` |
| `2.25` | `два кома двадцять п'ять` | `дві цілих двадцять п'ять сотих` |

### Current workaround
Власна функція `decimal_to_ua()` яка:
1. Розділяє цілу та десяткову частини
2. Конвертує кожну окремо через `num2words`
3. Додає суфікс залежно від кількості десяткових цифр:
   - 1 цифра → `десятих`
   - 2 цифри → `сотих`
   - 3 цифри → `тисячних`
   - 6 цифр → `мільйонних`

### Що виправити в num2words
Додати опцію `decimal_format: DecimalFormat::Fractional` або параметр `use_ordinal=True` для десяткових:
```python
num2words(36.6, lang='uk', ordinal=True)
# → "тридцять шість цілих шість десятих"
```

## 🟡 Проблема 3: Апостроф U+02BC замість U+0027

### Опис
`num2words` використовує `ʼ` (U+02BC Modifier Letter Apostrophe) замість звичайного `'` (U+0027 Apostrophe). Piper TTS не розпізнає U+02BC як фонему і видає warning `Missing phoneme from id map: ʼ`.

### Приклади
| num2words | Piper очікує |
|-----------|-------------|
| `пʼять` | `п'ять` |
| `шістʼнадцять` | `шістнадцять` |

### Current workaround
```rust
.replace('ʼ', "'")
```

### Що виправити в num2words
Використовувати стандартний ASCII apostrophe `'` (U+0027) замість U+02BC. Це сумісніше з TTS системами та загальним використанням.

## 🟡 Проблема 4: Відсутність підтримки від'ємних десяткових з правильним форматом

### Опис
`num2words(-5.5, lang='uk')` → `"мінус п'ять кома п'ять"`. Це не відповідає українській нормі.

### Очікується
`"мінус п'ять цілих п'ять десятих"`

### Current workaround
Обробляється в `num_to_ua()` — від'ємний знак обробляється окремо, потім десяткова частина конвертується через `decimal_to_ua()`.

---

## 🟢 Проблема 5: Відсутні скорочення для великих чисел

### Опис
Для HA може бути корисним формат типу `1.5K` → "одна тисяча п'ятсот". `num2words` не підтримує інженерні/HA скорочення.

### Приклади
| Ввід | num2words | Очікується |
|------|-----------|------------|
| `1K` | (не розпізнає) | `одна тисяча` |
| `2.5M` | (не розпізнає) | `два з половиною мільйони` |

### Поточне рішення
Не реалізовано — користувач має передавати повні числа.

## 📝 Рекомендації для num2words (UA)

### 1. Додати `gender` параметр
```rust
Num2Words::new(1.5)
    .lang(Lang::Ukrainian)
    .gender(Gender::Masculine) // для "один цілий"
    .to_words()
```

### 2. Додати `DecimalFormat` enum
```rust
enum DecimalFormat {
    Comma,       // "тридцять шість кома шість" (поточний)
    Fractional,  // "тридцять шість цілих шість десятих" (правильний)
}
```

### 3. Виправити апостроф
Замінити U+02BC → U+0027 за замовчуванням.

### 4. Додати `use_ordinal` для десяткових
При `true` — використовувати порядкові форми (`десятих`, `сотих`, `тисячних`).

### 5. Додати `engineering_notation`
Для підтримки `K`, `M`, `G`, `m`, `μ` префіксів.
