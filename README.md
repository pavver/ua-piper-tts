# Sherpa-UA TTS

Rust-проект для генерації аудіо з тексту українською мовою з використанням **Sherpa-ONNX**.

## Моделі

Проект підтримує дві українські TTS-моделі:

| Модель | Розмір | Спікери | Якість |
|--------|--------|---------|--------|
| `vits-coqui-uk-mai` | ~68 MB | 1 (жіночий) | Найкраща для української |
| `vits-piper-uk_UA-ukrainian_tts-medium` | ~92 MB | 3 | Використовує espeak-ng (обмежена якість) |

**Рекомендована модель:** `vits-coqui-uk-mai` — найкраща якість української вимови.

## Швидкий старт

### 1. Завантаження моделей

```bash
./download_models.sh
```

### 2. Запуск

```bash
cargo run
```

Аудіо-файли будуть збережені в директорії `output/`.

## Структура проекту

```
├── Cargo.toml              # Залежності (sherpa-onnx, hound)
├── src/main.rs             # Основний код TTS
├── download_models.sh      # Скрипт завантаження моделей
├── models/                 # Завантажені моделі (не комітяться)
├── output/                 # Згенеровані WAV файли (не комітяться)
└── README.md
```

## Додавання нового тексту

Відредагуйте змінну `text` у `src/main.rs`:

```rust
let text = "ваш текст тут";
```

## Додавання нової моделі

1. Додайте модель у `MODELS` в `src/main.rs`
2. Додайте посилання для завантаження в `download_models.sh`

## Залежності

- Rust (cargo)
- curl (для завантаження моделей)
- Sherpa-ONNX (автоматично через crates.io)

## Ліцензія

Моделі мають різні ліцензії — перевіряйте MODEL_CARD у кожній моделі.
